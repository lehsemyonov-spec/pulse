# Процесс работы агента

Правила взяты из инструкции `product-strategist` (AGENTS.md) и перенесены на разработку сайта.
Что перенесено, а что нет, описано в `decisions.md` (D1).

| Файл | Что в нём |
|---|---|
| `stages.md` | 9 этапов из BRIEF.md и критерии готовности каждого |
| `state.md` | где остановились, что следующее, открытые вопросы |
| `log.md` | журнал действий, включая ошибки и отклонения |
| `decisions.md` | решения и отступления от BRIEF.md, условия пересмотра |
| `unknowns.md` | чего не знаем и что может изменить решение |
| `cost.md` | затраты по этапам |

**Начало сессии:** прочитать `state.md` и последние записи `log.md`, показать, где остановились, и не повторять сделанное.
**Закрытие этапа:** проверка по критериям из `stages.md` → `state.md` → запись в `log.md` → строка в `cost.md` → сводка до 10 строк → ждём «ок» человека.
