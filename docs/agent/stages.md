## Критерии готовности

Общие для каждого этапа: `npm run build` проходит без ошибок (tsc + vite); в консоли браузера нет ошибок; скриншоты десктопа 1440×900 и телефона 390×844 просмотрены; цвета, шрифты и тексты совпадают с BRIEF.md; отступления от BRIEF.md записаны в `decisions.md`.

**Этап 1**
- [x] Vite + TypeScript без фреймворка, `npm run dev` / `build` работают
- [x] Цвета и шрифты из BRIEF.md заведены токенами в `src/styles/tokens.css`
- [x] Шрифты подключены локально, WOFF2 с кириллицей (Manrope 300–500, Cormorant Garamond Italic, JetBrains Mono 400)
- [x] 7 экранов в разметке (0 — прелоадер, 1–6 — секции) с `data-screen` и `data-shape`

**Этап 2**
- [x] 20 000 точек на десктопе, 8 000 на телефоне
- [x] Сердце строится из `public/shapes/heart.png` по правилу ТЗ (светлые пиксели → точки, яркость → глубина); без маски — процедурное 3D-сердце
- [x] Двойной удар «ту-дум», 72 уд./мин, скейл 1 → 1,04
- [x] Курсор раздвигает частицы, после ухода курсора они возвращаются
- [x] Bloom (UnrealBloomPass) + зерно 3–4%
- [x] Параметры в `src/config.ts`, lil-gui по `?debug`, в основной бандл не попадает
- [x] Pixel ratio ≤ 1,75; рендер на паузе, когда вкладка скрыта
- [ ] 55–60 fps на ноутбуке — **не проверено**: в облачной среде нет GPU (см. U2)

**Этап 3**
- [x] Формы всех экранов: сердце → хаос → город → руки → созвездия → кольцо (5 из ТЗ + созвездия экрана 5, без подсветки — она на этапе 6)
- [x] Lenis + ScrollTrigger; форма зависит от позиции скролла, а не от времени — работает в обе стороны
- [x] Волновой переход: у каждой точки задержка `aDelay` + пятно шума, в полёте curl-noise
- [x] Пара форм «из/в» меняется на границе экрана без скачка
- [x] Руки сближаются по скроллу (экран 4)
- [x] Десктоп 1280×800 и телефон 390×844: каждая форма читается (проверено по скриншотам)
- [x] Видео со скроллом вниз и быстро вверх — без рывков и пропусков форм
- [ ] Плавность при быстром скролле на реальном устройстве — **не проверено** (U2)
